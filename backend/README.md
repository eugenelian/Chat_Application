## Initialising Repository
Backend initialised with ```npm init -y```, ```npm i express mongoose dotenv jsonwebtoken bcryptjs cookie-parser cloudinary socket.io``` and ```npm i nodemon -D```

Installing CORS using ```npm i cors```
