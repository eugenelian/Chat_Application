# Chat_Application
Building a MERN-stack Chat Application using Node.js and React.js with in-app notifications 

# Running the application
Run ```npm run build``` 

# Deploying Application
- Select on Render's deployment option of 'Web Services'
- Change build command to ```npm run build``` and start command to ```npm run start```
- Paste all your env variables (except NODE_ENV) into Render
- Deploy Web Services once done
